# Installation

## Stable release

To install String Calculator Kata, run this command in your terminal:

```sh
uv add string_calculator_kata
```

Or if you prefer to use `pip`:

```sh
pip install string_calculator_kata
```

## From source

The source files for String Calculator Kata can be downloaded from the [Github repo](https://github.com/carlos016/string_calculator_kata).

You can either clone the public repository:

```sh
git clone git://github.com/carlos016/string_calculator_kata
```

Or download the [tarball](https://github.com/carlos016/string_calculator_kata/tarball/master):

```sh
curl -OJL https://github.com/carlos016/string_calculator_kata/tarball/master
```

Once you have a copy of the source, you can install it with:

```sh
cd string_calculator_kata
uv pip install .
```
